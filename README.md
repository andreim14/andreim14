### What I'm working on

**[Beanis](https://github.com/andreim14/beanis)** : a Redis ODM with vector search, aimed at RAG systems. Semantic search in roughly 50 lines of Python instead of wiring together half a dozen services. There's an [examples repo](https://github.com/andreim14/beanis-examples) too.
